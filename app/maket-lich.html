    2

    Thông tin khách

    Chưa có logo

    Ô nào để trống thì dòng đó được ẩn khỏi maket. Tên hoặc địa chỉ dài quá thì bấm Enter để xuống dòng, không thì chữ tự thu nhỏ cho vừa.

    2

    Danh sách khách

    File Excel/CSV có các cột: Tên công ty, Địa chỉ, Điện thoại, Email, Website, Logo (tên file ảnh). Hoặc dán thẳng từ Excel vào ô dưới.

    Logo của khách Tên file logo trùng tên công ty hoặc trùng cột Logo thì tự ghép.
    3

    Lớp trong file

    Phần mềm tự đoán lớp nào là tên, địa chỉ, điện thoại… theo tên lớp và nội dung chữ. Sai thì chọn lại ở cột bên phải. Trong “Khuôn chữ”, dấu {} là chỗ điền thông tin.

    Chưa mở file
    4

    Khung thông tin như mẫu

    Dùng khi file là ảnh JPG/PNG, hoặc PSD chưa có sẵn lớp chữ thông tin.

    5

    Phông chữ

    Máy thiếu phông của file PSD thì chữ sẽ vẽ bằng phông thay thế. Tải file phông (.ttf, .otf) lên để maket giống bản gốc.

      Chưa chọn chi tiết nào. Bấm vào một chi tiết trên maket, hoặc bấm tên lớp ở mục 3.
